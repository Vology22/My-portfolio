# 👨‍💻 My Portfolio

Приветствую! В этом репозитории собраны примеры моих работ. Стоит отметить, что здесь представлена лишь часть проектов: некоторые из них остались за рамками портфолио, так как являются приватными или защищены соглашением о неразглашении (NDA).

---

## 🛠 Проекты

### 🤖 Bot-auto-reg
**Telegram-бот для автоматизации рассылок и лидогенерации.**
* **Функционал:** Массовая рассылка сообщений по Telegram-группам для привлечения целевой аудитории.
* **Особенности:** * Встроенный автоответчик.
    * Автоматическая квалификация пользователя (проверка готовности к работе) перед переводом диалога на оператора.
    * Тонкая настройка параметров.
    * **Mobile-friendly:** Полная возможность управления ботом прямо со смартфона.

### 💬 BotDialog
**Инструмент для симуляции активности в Telegram-сообществах.**
* **Назначение:** Создание видимости живого общения в группах путем планирования длительных диалогов между несколькими аккаунтами.
* **Технологии:** Интеграция с нейросетями для генерации реалистичных и контекстных ответов.

### 🏋️ Bot-GYM
**Классический информационный бот-справочник.**
* **Суть:** Демонстрация реализации простого и понятного интерфейса для предоставления структурированной информации пользователю. Ничего лишнего — только эффективная доставка контента.

### 🔍 ParserHouzz
**Специализированный парсер для зарубежного рынка.**
* **Задача:** Сбор данных с немецкого портала *Houzz*.
* **Результат:** Автоматизированный поиск архитекторов и дизайнеров, извлечение их контактных данных и последующая сортировка.

### 🖼 ParserUserVK-GUI
**Парсер пользователей ВКонтакте с графическим интерфейсом.**
* **Функционал:** Сбор целевой аудитории из различных сообществ VK.
* **Особенности:** Наличие удобного GUI (графического интерфейса) для комфортного взаимодействия с программой без использования терминала.

### 🏢 Parser-Companies-2GIS-Yandex
**Мультиисточниковый парсер компаний с выгрузкой в Excel.**
* **Источники:** 2ГИС, Яндекс Карты, Яндекс/веб-поиск, сообщества VK и Telegram-чаты.
* **Результат:** Таблица `companies.xlsx` — название, телефон, email, сайт, адрес, регион, вид деятельности, источник.
* **Особенности:**
    * Playwright для «тяжелых» сайтов, автоматическое решение капчи через rucaptcha.
    * Умное слияние дублей между источниками (данные не теряются, а дополняют друг друга).
    * Поисковые запросы и города настраиваются в одном файле `config.py`.

### 📢 Bot-VK-Community
**VK-бот сообщества «три в одном».**
* **Объявления:** Прием объявлений через диалог с ботом, модерация, автопубликация на стену по расписанию, контроль подписки автора и продления.
* **Анализ конкурентов:** Поиск крупнейших пабликов по теме и городу.
* **Агрегатор:** Автоматический репост постов из заданных сообществ с категоризацией по источнику.
* **Особенности:** Полностью кнопочный интерфейс для пользователя и администратора, SQLite, Long Poll.

### 💼 Parser-HeadHunter
**Парсер вакансий и резюме с hh.ru.**
* **Технологии:** Selenium + BeautifulSoup, сохранение cookies для повторных сессий.
* **Особенности:**
    * Автоматическое решение капчи через rucaptcha.
    * Выгрузка результатов в Excel, прогресс-бар в консоли.
    * Сборка в `.exe` через PyInstaller для заказчика без Python.

### 🏠 Homeder-Fullstack
**Сервис поиска жилья в формате «свайпов» — сайт + Telegram-бот + API.**
* **Backend:** FastAPI + MySQL (пользователи, объекты, избранное, мэтчи).
* **Frontend:** React + TypeScript + Vite, анимации на Framer Motion.
* **Telegram-бот:** Синхронизирован с сайтом через общий API, геокодинг адресов через Яндекс.
* **Дополнительно:** Отдельный сервис мэтчей на C# (.NET 8).

### 📊 Monitor-Prices-Marketplaces
**Мониторинг цен на маркетплейсах с уведомлениями в Telegram.**
* **Функционал:** Сбор товаров с Мегамаркета и сравнение цен с Ситилинком, М.Видео, Технопарком и DNS.
* **Особенности:** Selenium с обходом JS-проверок, история найденных цен в SQLite, мгновенные уведомления о выгодных предложениях в Telegram.

### 🛒 Bot-YandexMarket-Poster
**Telegram-бот для автопостинга товаров с Яндекс Маркета.**
* **Функционал:** Парсинг карточки товара по ссылке (название, цена, фото) и публикация поста в подключенные каналы.
* **Особенности:** Автоматическое наложение водяного знака на изображения, админ-панель для управления каналами.

### 🪙 Bot-Crypto-Parser
**Telegram-бот для отслеживания криптовалют.**
* **Функционал:** Парсинг данных по токенам и публикация в канал.
* **Особенности:** Проверка подписки на канал, админ-панель (смена канала, поддержки, список токенов, добавление админов).

### 📅 Bot-Schedule
**Telegram-бот с расписанием занятий.**
* **Функционал:** Выдача расписания на день/неделю с автоматическим определением четной и нечетной недели.

### 🏷 Bot-Baraholka
**Telegram-бот барахолки для публикации объявлений.**
* **Функционал:** Пошаговая подача объявления (фото, описание, состояние, цена) и публикация в канал после проверки.
* **Особенности:** Проверка подписки, кнопка «Написать продавцу», жалобы на объявления, бан/разбан пользователей администратором.

## ⚙️ Запуск
Все ключи и токены вынесены в переменные окружения: скопируйте `.env.example` в `.env` внутри папки проекта и заполните значения.
