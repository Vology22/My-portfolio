# Парсер компаний: логистика и перевозка грунта по РФ

## Установка

```bash
pip install -r requirements.txt
playwright install chromium
```

## Запуск

```bash
python main.py
```

Результат — файл `companies.xlsx` со столбцами:
Название, Телефон, Email, Сайт, Адрес, Регион, Деятельность, Источник, Ссылка.

## Структура проекта

- `config.py` — список поисковых запросов (`SEARCH_QUERIES`) и городов (`CITIES`).
  Здесь правишь, что и где искать.
- `parsers/base.py` — модель данных `Company`, нормализация телефонов, `merge_company()`
  (слияние дублей между источниками вместо потери данных при дедупликации).
- `parsers/dgis.py` — парсер 2ГИС (поиск + карточки фирм).
- `parsers/yandex.py` — парсер Яндекс.Карт (поиск + карточки организаций).
- `parsers/websearch.py` + `parsers/ysearch.py` — парсер Яндекс.Поиска (обычная
  веб-выдача): собирает ссылки на сайты компаний и вытаскивает контакты регуляркой.
- `parsers/vk.py` — парсер ВКонтакте: открытый поиск по постам (`newsfeed.search`,
  нужен пользовательский `VK_ACCESS_TOKEN`), не по заранее заданным пабликам.
- `parsers/telegram.py` — парсер Telegram (Telethon): сплошное сканирование
  сообщений в чатах из `TELEGRAM_CHAT_IDS` (без фильтра по теме) на предмет
  телефона/email. Сессию генерирует `login_telegram.py` (запустить один раз
  вручную — попросит номер телефона и код).
- `main.py` — запускает все парсеры, сливает результаты через `merge_company()`,
  сохраняет в Excel атомарно (`*.tmp.xlsx` → `os.replace`). Резюмируемый: сам
  подхватывает `companies.xlsx` и пропускает уже обработанные задания
  (`companies.jobs.log`) — после любого обрыва просто перезапусти `python main.py`.
  Telegram (`collect_telegram()`) не привязан к городам/запросам — вызывается
  отдельным проходом после основной очереди.
- `debug/` — диагностические скрипты (`debug_2gis.py`, `debug_yandex.py`) для
  отладки конкретного источника с `headless=False` и сохранением скриншота/HTML.

## Если парсер 2ГИС перестал что-то находить

Верстка 2ГИС периодически меняется. Все CSS-селекторы собраны в начале
`parsers/dgis.py` в виде констант `SEL_*`. Чтобы найти новые:

1. Открой `https://2gis.ru/moscow/search/перевозка грунта` в Chrome.
2. Нажми F12 → вкладка Elements.
3. Найди нужный элемент (карточку, кнопку телефона, заголовок) и скопируй
   его class / селектор.
4. Обнови соответствующую константу `SEL_*`.

Можно также временно поставить `HEADLESS = False` в `config.py`, чтобы
видеть, что происходит в браузере во время парсинга.

## Добавление новых источников

Каждый источник — отдельный модуль в `parsers/`, который:
- принимает запрос/регион,
- возвращает список объектов `Company` (см. `parsers/base.py`).

Дальше подключается в `main.py` аналогично `parse_2gis`/`parse_yandex`/`parse_yandex_search`.
Avito сознательно не подключали — блокирует капчей (GeeTest v4 / hCaptcha) каждый
запрос, подробности в `CLAUDE.md`.

## Важные замечания

- В `config.py` есть `DELAY_BETWEEN_REQUESTS` — задержки между запросами,
  не убирай их совсем, чтобы не получить блокировку по IP.
- Если сайт начинает показывать капчу — попробуй увеличить задержки,
  снизить `max_results`, или использовать прокси (не входит в этот прототип).
